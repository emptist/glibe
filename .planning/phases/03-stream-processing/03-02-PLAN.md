  <files>src/glibe/leaf.gleam</files>
  <action>Add streaming detection functions to leaf.gleam. A growing leaf IS the YinLeaf/YangLeaf record (indices only). Start value and corner value read from `databar_list` at those indices when needed.

  1. **update_yin_leaf(growing: YinLeaf, idx: Int, databar_list: List(DataBar), sma_tiny: Float) -> YinLeaf**
     - start_val = list.get(databar_list, growing.start_idx).sma_tiny
     - corner_val = list.get(databar_list, growing.corner_idx).sma_tiny
     - If sma_tiny > start_val: NEW leaf born at idx (killing bar belongs to newborn)
       → return YinLeaf(start_idx: idx, end_idx: idx, corner_idx: idx)
       (previous leaf's end_idx = idx - 1 handled by caller when adding to list)
     - Else if sma_tiny < corner_val: update corner → YinLeaf(..growing, corner_idx: idx, end_idx: idx)
     - Else: extend end → YinLeaf(..growing, end_idx: idx)
  
  2. **update_yang_leaf(growing: YangLeaf, idx: Int, databar_list: List(DataBar), sma_tiny: Float) -> YangLeaf**
     - start_val = list.get(databar_list, growing.start_idx).sma_tiny
     - corner_val = list.get(databar_list, growing.corner_idx).sma_tiny
     - If sma_tiny < start_val: NEW leaf born at idx
       → return YangLeaf(start_idx: idx, end_idx: idx, corner_idx: idx)
     - Else if sma_tiny > corner_val: update corner → YangLeaf(..growing, corner_idx: idx, end_idx: idx)
     - Else: extend end → YangLeaf(..growing, end_idx: idx)
  
  3. **init_yin_leaf(idx: Int) -> YinLeaf** → YinLeaf(idx, idx, idx)
  
  4. **init_yang_leaf(idx: Int) -> YangLeaf** → YangLeaf(idx, idx, idx)
  
  Leaf laws (DESIGN.md §5):
  - Law 1: First bar (idx=0) opens both twins → init at 0
  - Law 2: Every bar in current yin AND yang leaf
  - Law 3: New high→new YinLeaf, new low→new YangLeaf. Threshold = leaf's start_val (from databar_list[start_idx]). Killing bar belongs to newborn. Shortest leaf = 1 bar (start=corner=end).</action>
