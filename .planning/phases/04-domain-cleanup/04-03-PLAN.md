## The fact, measured (before the change)

- `api/symbol.gleam:1` and `:4` declared
  `Symbol = Instrument = Asset on specific Market`. `Symbol` was a **9-field
  record describing a tradable thing** (market id, asset id, market symbol,
  base/quote assets, brokers, providers, venue). None of those 9 fields is
  read anywhere in `src/` or `test/`.
- `desk.gleam` had `Instrument(settings: Dict(Interval, TimeframeSettings),
  timeframes: Dict(Interval, Timeframe))` — **two parallel dictionaries with
  the same key**, plus `put_settings` / `get_settings` / `NoSuchSettings`.
- `timeframe.gleam` carried three up-arrow fields — `symbol`, `interval`,
  `market_type` — and **no settings**. `market_type` is never read.
- `engine.gleam` therefore needed `databar_processing(tf, bar, settings)` with
  settings passed from outside, and `sourcebar_gate` read `timeframe.interval`.
- `config.gleam` held `symbols` and `timeframe_settings` as
  `List(#(String, …))`, the second keyed by `"BTCUSDT_H1"` (one `String`
  carrying two facts), read with `list.find` in `get_symbol` / `config_get_tfs`.

That whole shape is the "绕圈子" R23 names: the main types were missing, so a
string key, a second dictionary and two lookup functions stood in for the type
relation. It is being **deleted, not adapted**.

## The target shape

```
Desk(brokers: Dict(BrokerId, Broker))
  └─ Broker(instruments: Dict(Symbol, Instrument), accounts: …)
       └─ Instrument(timeframes: Dict(Interval, Timeframe))       ← ONE dict
            └─ Timeframe(settings: TimeframeSettings, …bars/leaves/branches…)
```

- `Symbol` = the **spelling** a broker uses to name an instrument. Opaque value,
  built only at the configuration/text boundary (`from_string` / `to_string`).
  It carries **no** instrument facts. `Instrument` never stores its own name.
- `Interval` exists **only as the key** of `Instrument.timeframes`. A `Timeframe`
  never carries its interval, its symbol, or a market tag. The caller that
  selected a `Timeframe` from that dict already holds the interval; it passes it
  to `sourcebar_gate`.
- `TimeframeSettings` is **not an entity**: a 12-number parameter block whose
  only home is `Timeframe.settings`. No dictionary of settings, no config table
  of settings, no id, no lookup function.
- `config.gleam` expresses ownership with **typed values**, not composite
  strings. `AppConfig` holds a `Desk`; the two `List(#(String, …))` tables and
  their `list.find` accessors are deleted.

## Tests that pin the ruling

- Two different spellings are two different `Symbol` values; one spelling
  round-trips through the codec; a `Symbol` cannot be built from an instrument's
  fields (compile-time fact: those fields no longer exist).
- `Instrument` has exactly one collection: `timeframes`. No settings dictionary,
  no `NoSuchSettings`, no `put_settings` / `get_settings`.
- A `Timeframe` carries its own settings; two intervals can carry different
  settings **without any second dictionary**.
- `Desk ▸ Broker ▸ Instrument ▸ Interval ▸ Timeframe` still reaches a state.
- `config.default_config()` builds a `Desk` with real instruments and
  timeframes; there is no `"BTCUSDT_H1"` string and no `config_get_tfs`.
- `sourcebar_gate` is given its interval explicitly; the same `Timeframe` value
  can be closed under two different intervals without being rewritten.

## Explicitly out of scope (recorded, not hidden)

  `String` keys — **R26 (2026-11-09)**: no separate identity-typing plan is

  deliberately open; types get added one at a time, when a consumer needs one.
