# Phase 04 Plan 05 — adopt R24 A: the product web layer (2026-11-09)

**Status:** in progress. This plan *builds* the web layer, which is the step
`.planning/phases/04-domain-cleanup/04-04-SUMMARY.md` and `docs/DESIGN.md`
"the BEAM web layer, measured" both said adoption waits for.

## Authority

- R24 (owner): the web-layer framework is the **AI's** job, decided by writing
  demos and comparing measurements, not an owner ruling. The demos ran and
  recommend A. So the decision below is mine and is not put to the owner.
- R15: root stays Erlang-target. R18: `webclient/` stays the only JS-target
  package. R17: the view is the generated `.mjs`, not hand-written JS.
- R19: documentation-first / TDD — `////` naming this plan, types, `///` on
  every public item, `todo as "…"` bodies, tests first, then bodies.
- R21: constructors are named in full and prefixed by the type name.
- R22 / R23: no stand-in entities. The endpoint serves the **real**
  `config.default_config().desk`, not a demo `SettledBar(42, 123.5)`.

## Decision (measured, not adopted from prose)

**Adopt A — Mist + Wisp thin data endpoints in the root Erlang-target package;
no Lustre server components; no new browser asset.** A cost 72 Gleam lines /
22 Hex packages / 0 hand-written JS; B cost 124 / 23 plus an OTP runtime and a
14 KB client runtime for a DOM patch path a canvas chart cannot use; C cost 82
/ 14 but hand-writes the request edge Wisp supplies. All three have the same
browser asset, so the choice only changes the server half.

## Scope

- `gleam.toml` / `manifest.toml`: add `mist` + `wisp` (Hex only). No npm dep,
  no `target` change, no new package, no path dependency.
- `src/glibe/web/server.gleam`: one new module.
  - `pub type Route { RouteDeskPage | RouteDeskJson | RouteNotFound }` — the
    closed set of endpoints. A `String` path is not allowed to stand in for it.
  - `route(method, segments)` — pure, exhaustively testable.
  - `desk_to_json(desk)` — the real `Desk ▸ Broker ▸ Instrument ▸ Interval`
    chain, using `Symbol`/`BrokerId`/`Interval` codecs; no composite keys.
  - `page(desk)` — a server-rendered HTML table of the same chain, so a human
    can see the ownership structure without a browser script.
  - `handle_request(request)` — Wisp handler, `wisp_mist` adapter at `main`.
  - `main()` — start Mist on port 8610. Run with `gleam run -m glibe/web/server`
    so the root library keeps no global `main` slot (Stage F's replay CLI is
    still free to own it).
- `test/web_server_test.gleam`: tests written before the bodies. Pure route
  tests plus handler tests built with `wisp/simulate.request`, asserting status
  and body — not just string helpers.
- Stable docs afterwards: `docs/DESIGN.md`, `docs/STATE.md`,
  `.planning/ROADMAP.md`, `README.md`. The temporary decisions document stays
  at zero owner items; no document may link to it.

## Out of scope (recorded, not hidden)

- The chart itself, real SPA interaction, streaming, load testing: R17's chart
  library and the generated `.mjs` are not wired into a canvas yet.
- `bucket_ends(date: String)` → `gleam_time.Timestamp` at the ingest boundary:
  a separate boundary plan, already named in `api/interval.gleam`'s module doc.
- `Market` as a level of the ownership chain: R26, add types when a consumer
  appears. This endpoint is a consumer of the existing four levels, not of a
  fifth.
- HTML escaping of arbitrary user-supplied strings: configuration values here
  are literals in `config.gleam`, not untrusted input. Recorded as debt.
